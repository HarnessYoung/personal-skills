Repository layout

skills/<name>/
  SKILL.md        # the skill (YAML frontmatter + instructions)
  skill.json      # version, provenance, verification record
  CHANGELOG.md    # SemVer history
  NOTICE.md       # upstream attribution
  references/     # progressive-disclosure docs
  scripts/        # executable helpers

Versioning

Skills use SemVer independently of the tools they wrap. Major = breaking workflow change, minor = new capability, patch = clarification. Each skill also records the exact tool version it was last verified against, so staleness is visible rather than implicit.

Provenance

Every skill declares an origin: original, derivative-enhancement, or vendored. Derived skills name the upstream repo, keep its license, and include a file-level breakdown of what is inherited versus original. See registry.json for the machine-readable index.
