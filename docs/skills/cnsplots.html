cnsplots

Publication-quality scientific figures in Python with Cell, Nature, and Science styling.

v1.0.0 derivative-enhancement BSD-3-Clause verified · cnsplots 0.6.0

Generates, revises, and debugs publication-quality scientific figures in Python using the cnsplots package. Triggers on requests for journal-style plots, multi-panel figures, survival/volcano/GSEA/ROC/heatmap plots, or Illustrator-editable vector output.

Upstream ships its own skill. Running cnsplots skill install installs the official version. This one adds executable verification on top. Prefer upstream if you want to track it exactly.

What it adds over upstream

check_env.py

Reports interpreter, package version, backend, and whether mutool is installed before any plotting.

inspect_api.py

Prints the installed signature and docstring so the agent stops guessing at API shapes that shift between releases.

validate_output.py

Checks the artifact exists, is non-empty, has correct magic bytes, and counts SVG text elements to catch text flattened into paths.

troubleshooting.md

13 documented failure modes with fixes.

Workflow the skill enforces

  • Probe the environment before writing code.
  • Inspect the data, then confirm each function signature against the installed version.
  • Build with matplotlib.use("Agg") for headless runs.
  • Save, then validate the artifact - never claim success on unrun code.
  • Report the script, output path, and every scientific assumption made.

Two traps it guards against

Pixels, not inches

cns.figure(180, 150) is 180×150 pixels. Writing cns.figure(6, 4) out of matplotlib habit yields a 6×4 pixel canvas.

Return types are not uniform

heatmapplot and dotplot return backend-native plotter objects, vennplot returns a matplotlib-venn object, and upsetplot returns panel axes. None are a plain Axes, so a bare .set(...) raises AttributeError.

Verified example

import matplotlib
matplotlib.use("Agg")

import cnsplots as cns

df = cns.datasets.load_dataset("tips")

mp = cns.multipanel(max_width=540)
ax_a = mp.panel("A", width=150, height=150)
cns.boxplot(data=df, x="day", y="total_bill", ax=ax_a)
ax_b = mp.panel("B", width=150, height=150)
cns.scatterplot(data=df, x="total_bill", y="tip", ax=ax_b)
cns.savefig("multipanel.svg")
